- [Portfolio](https://github.com/samuelecorra/portfolio) — my technical hub and public index of work. [Visit the site](https://samuelecorra.dev).

## Engineering principles

- Evidence before claims.
- Bound probabilistic components with explicit, testable rules.
- Unknown values stay unknown; I do not fill gaps with guesses.
- Documentation includes assumptions, failure modes, and limits.
